# Rakit UI

A React component library built on Tailwind CSS v4, published as `@rakit-ui/ui`.

## Install

```bash
pnpm add @rakit-ui/ui
```

## Wire up Tailwind

```css
@import "tailwindcss";
@import "@rakit-ui/ui/styles.css";
@source "../node_modules/@rakit-ui/ui/dist";
```

## Use a component

```tsx
import { Button } from "@rakit-ui/ui";

export function Example() {
  return <Button variant="primary">Get started</Button>;
}
```

Browse the **Components** section in the sidebar for every component, its variants, and interactive controls. See the **Theming** page for how to customize design tokens.
