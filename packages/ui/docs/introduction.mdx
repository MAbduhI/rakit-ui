# RakitMimpi UI

A React component library built on Tailwind CSS v4, published as `@rakitmimpi/ui`.

## Install

```bash
pnpm add @rakitmimpi/ui
```

## Wire up Tailwind

```css
@import "tailwindcss";
@import "@rakitmimpi/ui/styles.css";
@source "../node_modules/@rakitmimpi/ui/dist";
```

## Use a component

```tsx
import { Button } from "@rakitmimpi/ui";

export function Example() {
  return <Button variant="primary">Get started</Button>;
}
```

Browse the **Components** section in the sidebar for every component, its variants, and interactive controls. See the **Theming** page for how to customize design tokens.
