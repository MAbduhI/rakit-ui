# Rakitmimpi UI

A React component library built on Tailwind CSS v4, published as `@rakitmimpi-ui/ui`.

## Install

```bash
pnpm add @rakitmimpi-ui/ui
```

## Wire up Tailwind

```css
@import "tailwindcss";
@import "@rakitmimpi-ui/ui/styles.css";
@source "../node_modules/@rakitmimpi-ui/ui/dist";
```

## Use a component

```tsx
import { Button } from "@rakitmimpi-ui/ui";

export function Example() {
  return <Button variant="primary">Get started</Button>;
}
```

## Light and dark

Both themes ship in `styles.css`. Dark mode turns on when `<html>` carries
`data-theme="dark"`, or when the OS prefers dark and no explicit choice is
stored. The `useTheme()` hook handles both:

```tsx
import { useTheme } from "@rakitmimpi-ui/ui";

const { resolvedTheme, toggleTheme } = useTheme();
```

Use the **Theme** control in the toolbar to preview any story in either theme.

Browse the **Components** section in the sidebar for every component, its variants, and interactive controls. See the **Theming** page for the full token table, contrast measurements, and how to customize tokens, and **Utilities** for the `cn` and `debounce` helpers.
